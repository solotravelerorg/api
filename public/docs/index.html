Solo Traveler API Documentation

Base URL: https://api.solotraveler.org

Countries

The countries endpoint returns 249 ISO 3166-1 country and territory records.

GET /v1/countries
GET /v1/countries/{code}

Supported query parameters:

ParameterDescription
qSearch by country name, official name, alpha-2 code, alpha-3 code, or numeric code.
limitLimit number of records returned.
offsetSkip records for pagination.
 
curl "https://api.solotraveler.org/v1/countries?q=canada"

Airports

The airports endpoint currently provides a starter sample of major international airports.

GET /v1/airports
GET /v1/airports/{iata}

Supported query parameters: country, q, limit, and offset.

Airlines

The airlines endpoint currently provides a starter sample of major international airlines.

GET /v1/airlines
GET /v1/airlines/{iata}

Supported query parameters: country, q, limit, and offset.

OpenAPI

A machine-readable API specification is available at /openapi.json.
